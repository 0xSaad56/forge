# Code of Conduct

## Our pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Giving and accepting constructive feedback
- Focusing on what is best for the community and the project’s local-first goals

Unacceptable behavior includes:

- Harassment, insults, or personal attacks
- Publishing others’ private information without permission
- Conduct that is illegal or clearly unethical in the context of security tooling

## Enforcement

Project maintainers may remove comments, commits, or contributions that violate this Code of Conduct, and may ban contributors for serious or repeated violations.

## Scope

This Code of Conduct applies within project spaces and when an individual is representing the project in public spaces.
