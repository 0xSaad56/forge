# Code of Conduct

## Our standard

Contributors are expected to behave professionally and respectfully. Harassment, discrimination, personal attacks, deliberate disruption, and malicious behavior toward other contributors are not acceptable.

## Security research

Security research shared through this project must be presented in an authorized, educational, defensive, or otherwise lawful context. Do not publish credentials, private information, or unauthorized access material.

## Enforcement

Project maintainers may remove content or restrict participation when conduct violates this code or creates a security or community risk.
