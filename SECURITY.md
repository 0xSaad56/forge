# Security Policy

## Supported Versions

Forge is under active development. Security fixes are prioritized for the latest version on the default branch.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

If you discover a security issue in Forge, use GitHub's private vulnerability reporting when it is enabled for the repository. Include:

- a concise description of the issue;
- the affected component or file;
- reproducible steps;
- security impact; and
- supporting evidence where appropriate.

Do not include real credentials, private data, or secrets in a report.

## Scope

Relevant reports include vulnerabilities affecting:

- local API endpoints;
- file and path handling;
- authentication or authorization;
- prompt/retrieval injection boundaries;
- sensitive-data exposure;
- dependency vulnerabilities;
- unsafe command execution; and
- other issues that materially affect Forge's security.

## Responsible Use

Forge is intended for authorized security research, education, defensive analysis, and controlled laboratory environments.
